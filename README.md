# Contabilizei — Case PS

Material do case de Processo Seletivo para a Contabilizei.

## Estrutura

- `Case_PS/Apresentação/` — storyline, outline e speaker notes da apresentação
- `Case_PS/Entrega/` — entregável final: `index.html` (relatório interativo com Plotly), `case_contabilizei.pptx`, `gen_pptx.py`, `heatmap_corr.png`
- `Case_PS/Pesquisa/` — notas de pesquisa (mercado, concorrentes, tendências, etc.)
- `Case_PS/Referencias/` — material de referência original (enunciado e planilha)

## Site

O `index.html` em `Case_PS/Entrega/` é o relatório interativo publicado.
Quando deployado no Vercel, é servido na raiz via `vercel.json` (rewrite de `/` para o HTML).
